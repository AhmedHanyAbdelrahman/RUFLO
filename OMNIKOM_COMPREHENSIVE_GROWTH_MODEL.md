## PART I: SUPPLY ACQUISITION — DISTRESSED SELLER ENGINE

### 1.1 The 10 Distress Signal Taxonomy

California has ~1.4M "distress-eligible" properties at any given time across all 10 signal types. The key insight: **most operators fish from 1–2 signal types; Omnikom fishes from all 10 with systematic list stacking.**

#### Signal Type 1: NOD / Pre-Foreclosure
- **Universe**: ~85,000 active NODs in California (eff. Jan 2026 post-AB 2424)
- **AB 2424 Impact** (eff. Jan 1, 2025): 67% FMV price floor at trustee sale; extends NOD-to-auction to 111–266 days. Creates a **longer pre-auction negotiation window** — sellers have more time to explore options.
- **Data source**: County recorder (same-day via PropertyRadar); ForeclosuresDaily ($99–299/county)
- **CPL via outreach**: Cold mail $180–400; cold call $80–200; door knock $40–120
- **Conversion cold**: 1–3%; triple-stacked with absentee + tax delinquent: 5–8%
- **Compliance**: CC §1695 (HESCA) — 5-day cooling-off on NOD acquisitions; 2-year rescission risk; CC §2945 Foreclosure Consultant Act — requires DOJ registration + $100K surety bond if platform is classified as a "foreclosure consultant." **Mitigation**: Frame as "seller options education" not foreclosure assistance; structure as licensed brokerage referral not direct intervention.
- **Best avatar**: "Behind But Fighting" Maria (underwater, late payments, 90–180 days to auction)

#### Signal Type 2: Tax Delinquent (2+ Years)
- **Universe**: ~180,000 tax-delinquent properties in California
- **Data source**: County Tax Collector (public record, updated monthly); PropStream/BatchLeads merged platform ($99–449/month)
- **Triple-stack premium**: Tax delinquent 2+ yrs + absentee + high equity = 5–8% conversion vs 0.5–2% cold. **This is the #1 list stack** in California.
- **CPL**: $50–120 on stacked list vs $200–400 cold
- **Compliance**: Standard; no special California rules for tax delinquent outreach
- **Best avatar**: "Overwhelmed Landlord" Robert (absentee, stopped paying taxes, equity-rich)

#### Signal Type 3: Probate / Inherited Property
- **Universe**: ~65,000 probate filings/year in California involving real property
- **Data source**: Superior Court probate filings (NOT recorder — court data is 42× more leads in PropertyRadar's CA database); ForeclosuresDaily probate list
- **Outreach**: Direct mail to heirs/estate representatives; probate attorney referral network
- **AB 633/AB 2016**: Heir property partition protections — must notify all heirs; mandatory mediation before partition action. **Do not skip heir notification steps.**
- **CPL**: $120–300 via mail; $0 via probate attorney referral (relationship-based)
- **Compliance**: SB 1079 45-day eligible bidder window; AB 2016 heir notice requirements
- **Best avatar**: "Inherited Chaos" Jennifer (out-of-state heir, property needs work, just wants out)

#### Signal Type 4: Absentee Owners (Landlords Exiting)
- **Universe**: ~420,000 absentee-owned SFR properties in California
- **Data source**: PropertyRadar (filters: owner mailing address ≠ property address + 5+ yr tenure + no recent activity); ATTOM Data (enterprise API)
- **Sub-signals that elevate intent**: Code violations on absentee property; tenant complaints (public record); expired section 8 contracts
- **CPL**: $80–200 cold; $30–80 when stacked with code violation or tax delinquency
- **Best avatar**: "Burnt-Out Landlord" Robert (tired of management, wants to 1031 or cash out)

#### Signal Type 5: Expired Listings (MLS)
- **Universe**: ~18,000–25,000 expired listings/month in California
- **Data source**: REDX ($40–80/month) — best for real-time MLS expired data; Vulcan7
- **Conversion premium**: Seller already attempted retail sale → open to alternatives → 2× conversion vs cold list
- **CPL**: $40–100 via cold call; $25–60 via REDX data + script
- **Best avatar**: "Overpriced and Frustrated" (listed at wrong price, now open to creative solutions)

#### Signal Type 6: Code Violations
- **Universe**: ~95,000 active code violation notices in California (LA County alone: ~35,000)
- **Data source**: City/county building department public records; PropStream code violation filter
- **Insight**: Owner receiving daily fines is highly motivated. Frame: "We can take the property as-is and handle all violations."
- **CPL**: $60–140; pairs excellently with absentee filter (absentee + code violation = 8–12% conversion)
- **Best avatar**: "Deteriorating Asset" — absentee landlord, can't afford repairs

#### Signal Type 7: Vacant Properties
- **Universe**: ~95,000 vacant SFRs in California
- **Data source**: DealMachine AI Street View analysis (best driving-for-dollars app — $119/month); USPS Vacant/Seasonal indicators on PropStream
- **Outreach**: Door knock + direct mail; vacancy is visible signal
- **CPL**: $16–50 (door knock lowest CPL of any channel); DealMachine AI Street View $20–40/lead
- **Best avatar**: "Zombie Property" owner — may not even know it's vacant; absentee + vacant is goldmine

#### Signal Type 8: Divorce / Marital Dissolution
- **Universe**: ~80,000 divorce filings/year in California involving real property
- **Data source**: PropertyRadar court-sourced divorce (Superior Court filings — 42× more leads than recorder-sourced deeds); divorce attorney referral network
- **CPL**: $90–200 cold mail; $0 via divorce attorney reciprocal referral
- **Timing**: File at dissolution, not after. Seller often needs resolution before case closes.
- **Best avatar**: "Forced Sale" — divorcing couple, both parties motivated to liquidate quickly

#### Signal Type 9: High-Equity Long-Tenure (5+ Years, No Mortgage Activity)
- **Universe**: ~650,000 properties in California (owner 10+ yrs, 70%+ equity, no refi in 5 yrs)
- **Data source**: PropertyRadar equity filter + tenure filter; ATTOM equity data
- **Insight**: Not distressed — but ready for a life transition (downsizing, retirement, 1031). Highest-quality leads for retail listing and novation paths.
- **CPL**: $120–350 (harder to identify motivation; requires more touches)
- **Conversion**: 3–7% on equity-rich long-tenure lists

#### Signal Type 10: Driving for Dollars (D4D)
- **Universe**: Unlimited — any neighborhood
- **Best tool**: DealMachine ($119/month) with AI Street View analysis; photo-log vacant/distressed properties; auto-add to CRM with owner skip trace
- **CPL**: $16/lead (industry benchmark — lowest of all channels)
- **Conversion**: 1–4% cold; 8–15% when D4D is combined with absentee + code violation confirmation
- **Compliance**: No specific concerns; public street observation only

#### Stakeholder 3: Title / Escrow Companies

**What they bring**: Transaction processing (closings); data on assignments, double-closes, novations; early warning on distressed title (liens, lis pendens); investor-friendly closings.

**Acquisition**:
- Attend REITA (Real Estate Investors of Title Agents) or local REIAs — title companies actively exhibit
- Target "investor-friendly" title companies specifically (specialize in wholesale, novation, double-close)
- Direct approach: "We close 10+ transactions/month; we want a dedicated escrow officer and priority turnaround"

**Compensation structure (CRITICAL — RESPA Section 8 restriction)**:
- **NO cash referral fees** between Omnikom (as a settlement service referral source) and title company on federally related mortgage transactions
- RESPA Section 8(a) prohibits kickbacks for referrals involving federally related mortgages
- **Permissible structures**:
  - Affiliated Business Arrangement (ABA): Omnikom creates or co-owns a title entity → receives dividends (not referral fees)
  - Marketing Services Agreement (MSA): Title company pays fair-market value for actual marketing services rendered (lead generation, co-branded content) — must be documented and defensible
  - Volume pricing: Title company provides discounted fees to Omnikom sellers/buyers (not a kickback — it's a bulk discount)
- Cash-only transactions: RESPA does not apply → referral fee permissible

**Value exchange (non-fee)**:
- Exclusive preferred vendor relationship for all Omnikom closings
- Co-branded marketing (Omnikom promotes title company to partner network)
- Dedicated escrow officer and 24-hour turnaround guarantee

**What they fear**: Liability from complex/creative transactions (assignments, double-closes, subject-to). **Address**: Provide title company with Omnikom's transaction playbook for each exit path. Demonstrate that structure is legally documented and insured.

**Compensation structure (CRITICAL — Ethics restriction)**:

In exchange, we'd love to send clients who need estate planning to your office."

#### Stakeholder 10: Novation Buyers (Retail Buyers via Creative Structure)

**What they bring**: Retail buyers who purchase the property at or near market value through the novation structure, generating 2–3× more profit for Omnikom than a wholesale assignment.

**How novation works**: Omnikom contracts to purchase from distressed seller → before closing, substitutes a retail buyer into the contract with seller's written consent → buyer closes directly with seller; Omnikom earns the spread between seller's accepted price and buyer's market price.

**Acquisition channels for novation buyers**:
- MLS listing via agent partner (after novation assignment — buyer pool is full retail market)
- Open houses (drives qualified buyer traffic to the specific property)
- Buyer agent network (Omnikom pays 2.5–3% buyer agent commission to activate agent network)
- Facebook Marketplace + Zillow Make Me Move listings

**Legal structure**: Novation requires written consent from all parties (seller, buyer, Omnikom). California Civil Code §1531 governs novation. Must be disclosed clearly to seller. **Risk**: If buyer defaults after novation assignment, seller may have claims against Omnikom — carry E&O insurance and use attorney-drafted novation agreement.

### 4.4 KYC/AML / FinCEN Compliance Stack

**FinCEN Residential Real Estate Rule** (eff. March 1, 2026):
- Mandatory beneficial ownership disclosure on **ALL cash/entity purchases** of residential real property nationwide
- Requires identification of UBO (Ultimate Beneficial Owner) — all natural persons owning 25%+ of purchasing entity
- Reporting to FinCEN GTO portal within 30 days of closing
- **Who must report**: Settlement agents, title companies (primarily), but platforms facilitating the transaction should ensure compliance and collect documentation
- **Omnikom protocol**: Collect UBO documentation at offer acceptance; pass to title company with deal package; verify FinCEN filing is complete before deal is marked closed

**6-Layer KYC/AML Stack**:
1. **Identity verification**: Government-issued ID + liveness check (Persona.com or Jumio — $1–3/verification)
2. **Entity verification**: Articles of incorporation, EIN, operating agreement for LLC/trust purchasers
3. **UBO identification**: FinCEN-required beneficial ownership form (25%+ threshold)
4. **Sanctions screening**: OFAC SDN list + FinCEN watchlist (automated via Persona or Alloy)
5. **Source of funds**: Bank statement for cash purchases; draw authorization for hard money
6. **Ongoing monitoring**: Re-screen at each new transaction; flag changes in entity ownership

**Seller Impersonation Fraud** (fastest-growing fraud type in real estate, 2025):
- Protocol: Video verification call with seller before contract execution; match ID to face (liveness check); require notarized documents for remote transactions; wire instructions must come from verified seller email (ClosingLock recommended)
- Signs of fraud: Seller only communicates by text/email; refuses video call; instructions to send funds to unusual account; urgency pressure to skip standard process

**Wire Fraud** ($275.1M in real estate wire fraud losses in 2025):
- Never send wire instructions via unsecured email
- Use ClosingLock or Qualia for encrypted wire instruction delivery
- Verbally verify wire instructions with title company by phone to confirmed number before any wire
- Cybersecurity training for all team members handling transactions
