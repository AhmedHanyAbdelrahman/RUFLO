# Omnikom Website Developer Handoff

This package contains the complete strategic, content, design, and engineering specification for the Omnikom Revenue Infrastructure website.

## Read in This Order

1. `01_omnikom_product_vision_business_architecture.md`
   - Defines the company, category, platform, Revenue Lanes, industries, commercial model, operating model, KPIs, compliance boundaries, and Rainmaker partnership architecture.

2. `02_omnikom_website_ux_copy_customer_journey.md`
   - Defines the sitemap, visitor journeys, complete page structure, website copy, industry pages, solution pages, Revenue Lane pages, consultation funnel, SEO, FAQs, and the Financial Services partnership landing page.

3. `03_omnikom_design_system_engineering_specification.md`
   - Defines the Sharp & Systematic design language, tokens, components, responsive behavior, motion, accessibility, Next.js architecture, CMS, CRM/forms, analytics, security, testing, deployment, and acceptance criteria.

## Important Build Rules

- Omnikom is positioned as **Revenue Infrastructure**, not a call center, VA company, lead vendor, or generic agency.
- The public product is a **Revenue Acquisition Lane**, not a caller pod.
- Do not publish fixed pricing unless leadership explicitly approves a strategy change.
- Do not promise revenue, closed deals, transactions, policies, cases, or commissions.
- Omnikom owns the managed infrastructure; clients own sales conversion, regulated activity, closing, and fulfillment.
- The Financial Services page should be titled **Omnikom Financial Services Infrastructure — Powered by Rainmaker Wealth Innovation**.
- Use the Omnikom Sharp & Systematic visual system: near-black, royal blue, lime, white, flat high-contrast blocks, no gradients, no glow, and no generic call-center imagery.
